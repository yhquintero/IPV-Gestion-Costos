# 16. Decisiones pendientes

> Entregable §39‑16 · [Índice](README.md)

**Importante**: este documento **no responde** las preguntas abiertas del §37 del prompt maestro (corresponde al propietario). Aquí se listan las decisiones **adicionales o complementarias** que surgieron del análisis. La columna *Recomendación* es una **propuesta técnica provisional**, no una decisión. Todo lo marcado ⛔ **PENDIENTE DE DEFINICIÓN** sigue así hasta que el propietario o una fuente normativa lo confirme.

## 16.1 Las decisiones que condicionan todo lo demás (resolver primero)

| Orden | Decisiones | Por qué bloquean |
|---|---|---|
| 1 | **D‑05** proveedor de licencias + dictamen legal · **D‑06** hosting y jurisdicción | Determinan si Keygen Cloud es viable, dónde se aloja todo y qué pagos son posibles |
| 2 | **D‑01** significado y orden de IPV/Ficha · **D‑02** normativa aplicable | Determinan el modelo del Control IPV y las reglas |
| 3 | **D‑03** política de tasa · **D‑04** token y términos de elTOQUE | Determinan qué tasa congela una ficha y si la API cubre los instrumentos |
| 4 | **D‑08** precios · **D‑09** derechos por política · **D‑12** base de renovación | Determinan el catálogo comercial y la lógica de renovación |
| 5 | **D‑15** alcance de Cuadre Pinar · **D‑07** modelo de despliegue | Determinan el tamaño del MVP y el aislamiento |

## 16.3 Cómo se cierran

Cada decisión resuelta se registra en un **ADR** (el primero, [ADR‑0001](adr/0001-reabrir-offline-y-multisucursal.md), ya está propuesto; los siguientes figuran en el [índice de ADR](adr/README.md)) y se actualiza el documento afectado. Si una decisión depende de una norma o dictamen externo, se anota la **referencia exacta** (gaceta, resolución, carta de elTOQUE, dictamen) en el ADR.
